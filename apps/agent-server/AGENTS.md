# Agent Server 开发约定

本文件补充[根目录约定](../../AGENTS.md)，仅列出 `apps/agent-server` 的开发约束。模块职责、会话流程和验证命令见 [README](README.md)。

## 实现约束

- 仅维护连接所需的会话映射、附件和展示信息；不另建 D2C 工作流或维护第二套执行状态。
- HTTP 路由不直接创建 Codex 进程或实现设计工具，通过服务接口转发操作；Codex 原生协议适配留在 `codex-client`。
- 运行资源通过显式构造参数或工厂统一装配与释放；会话操作、事件订阅和展示数据转换分别维护。
- 同一运行目录只允许一个活动服务；初始化任务索引前取得进程锁，关闭 Codex 连接后释放锁。
- 客户端断开只能取消当前订阅；显式停止必须绑定指定任务和轮次，不得关闭其他任务使用的共享进程。
- 回答和审批必须绑定当前会话及有效请求，按用户实际决议转发；错误响应保留请求标识并给出可理解的信息。

## 日志与验证

- 使用结构化日志记录请求、任务或会话标识、操作及结果，便于追踪跨入口调用。
- 不记录认证信息、完整环境变量、规则全文或原始设计载荷，不直接序列化请求和异常对象。
- 会话与连接变更重点覆盖多入口访问、断开重连、指定任务停止，以及失效或被拒绝的审批请求。
