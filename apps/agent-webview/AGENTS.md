# Agent Webview 前端约定

本文件补充[根目录约定](../../AGENTS.md)，适用于 `apps/agent-webview`。Webview 保留 ui-forge 自有页面，负责输入、展示和用户交互；以下产品交互对应当前 Codex 接入。

## 组件与目录

- `src/app` 负责应用入口、依赖组装、主题和顶层路由；页面、组件和页面状态按功能组织在 `src/features`。
- 每个 `.tsx` 文件只定义一个 React 组件，文件名与组件名一致；Props 和辅助类型可与组件同文件维护。
- `src/data-sources/<domain>` 提供业务数据源；`src/communication` 维护通信接口与传输适配，由应用入口统一注入。仅跨功能复用且无业务语义的内容进入 `shared`。

## 技术与样式

- 使用 React、Ant Design 和 Vite。TypeScript 与 TSX 的相对导入省略扩展名，样式等资源保留扩展名，遵循本工作区的 Bundler 配置。
- 功能样式默认使用 CSS Modules；`src/styles.css` 只维护 reset、全局 Token 和应用壳层样式。功能级普通 CSS 必须限定在对应根类下。
- 优先使用 Ant Design `ConfigProvider` 和组件 Token 定制样式，不依赖内部 DOM 层级、哈希类名或大量 `!important`。

## 数据与状态

- 页面经 Extension 消息桥接访问本地服务；开发和测试可注入替代传输。功能组件只消费已校验的数据源方法与事件，不直接调用 HTTP、`acquireVsCodeApi` 或 Codex。
- 执行状态以服务返回的会话和工具事件为准；本地只维护输入、展示及交互状态，不用 Reducer 或定时器模拟任务执行。
- 简单状态使用 `useState` 并就近维护；派生值直接计算。复杂交互确有需要时再使用 `useReducer` 或提取 Hook、Controller。
- 请求、订阅和跨组件复用逻辑可提取为功能级 Hook，并明确清理副作用。组件卸载只清理前端资源，不隐式发送任务停止请求。
- Mock 和测试样本仅用于开发入口和测试，明确标识；生产入口与组件不导入模拟任务或固定执行结果。

## 用户交互

- 任务页面支持设计链接或图片和需求输入。
- 新增独立的配置页面路由，支持查看、编辑并保存 `design.md`、`project.md` 的内容。展示真实的加载与保存结果，保存失败时保留用户尚未保存的编辑。
- 按实际会话消息和工具活动展示进度，不预设必须依次经过的设计、Coding、Review 阶段。
- 展示真实的问题和审批内容，用户回答或决议携带对应请求标识提交；请求失效时更新界面，不自动确认或沿用旧决议。
- 同一任务可跨页面与 CLI 访问，重连后依据服务数据恢复展示；断开连接与显式停止任务是不同操作。
- 会话结束与验收结论分开展示，区分通过、失败和未验证；截图及结果必须来自真实工具输出。

## 验证

- 工作区类型检查使用 `npm run typecheck -w @ui-forge/agent-webview`；浏览器交互变化运行对应 E2E。
- 相关测试覆盖配置页面路由、规则内容加载与保存、输入错误、事件更新、回答与审批、重连及验收状态展示；其他检查按根目录约定执行。
