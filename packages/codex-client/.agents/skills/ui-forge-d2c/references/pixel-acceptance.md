# 严格像素比较

仅当用户或任务规则要求严格像素指标时读取本参考资料。

优先使用项目已有的比较器。否则调用 `scripts/compare_screenshots.py`，通过 `--help` / `--version` 确认参数，并使用本次任务的阈值。保留实际截图、差异图和 JSON 结果。

原始图片与截图必须具有相同的视口、像素尺寸和页面状态，包括设计中出现的悬停状态。等待字体和图片稳定加载，并禁用动画。不要拉伸参考图进行比较。其他视口下的布局应单独验证。

说明因缺少完全一致的字体或原始渲染环境而产生的差异。没有新证据时不要反复微调 CSS。未达到严格阈值时如实报告。

首先检查本次任务的设计输入或已授权设计工具是否提供原始全屏参考图。如果没有，请用户提供原图，或提供相同视口与状态下的授权导出图。不得使用登录页、根据结构推断的图片或之前任务的截图替代，也不得绕过认证。可以继续独立的功能检查，但必须将严格像素验收标为受阻。比较器读取错误不等于完成像素比较，也不能证明页面已经通过。
